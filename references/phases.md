## Phase 1 — Reconnaissance

### recon.js usage
```bash
node scripts/recon.js https://example.com --out recon/
# Options:
#   --viewport 1440,768,375   (default: all three)
#   --wait 2000               (ms to wait after load for animations to settle)
#   --interact                (sweep interactive states: hover, click, scroll)
```

### Manual recon (no puppeteer)

If `scripts/recon.js` is unavailable, use `web_fetch` to retrieve HTML/CSS, then:

```bash
# Extract computed styles via browser devtools snippet (paste in console):
JSON.stringify(
  Array.from(document.querySelectorAll('*')).reduce((acc, el) => {
    const styles = getComputedStyle(el);
    ['font-family','font-size','font-weight','color','background-color',
     'padding','margin','gap','border-radius'].forEach(prop => {
      const val = styles.getPropertyValue(prop);
      if (val && val !== 'rgba(0, 0, 0, 0)' && val !== 'none' && val !== '0px') {
        acc[el.tagName + '.' + el.className.split(' ')[0]] = acc[...] || {};
        acc[el.tagName + '.' + el.className.split(' ')[0]][prop] = val;
      }
    });
    return acc;
  }, {})
)
```

Save output to `recon/manual-computed-styles.json`.

## Phase 3 — Component Specs

### Spec extraction helper (browser console)

Paste this snippet on the original page to generate a spec skeleton for a selector:

```javascript
function specFor(selector) {
  const el = document.querySelector(selector);
  if (!el) return 'Element not found';
  const cs = getComputedStyle(el);
  const rect = el.getBoundingClientRect();
  return {
    selector,
    geometry: {
      width: rect.width, height: rect.height,
      padding: cs.padding, margin: cs.margin,
      display: cs.display, flexDirection: cs.flexDirection,
      gap: cs.gap, alignItems: cs.alignItems, justifyContent: cs.justifyContent,
      gridTemplateColumns: cs.gridTemplateColumns,
    },
    typography: {
      fontFamily: cs.fontFamily, fontSize: cs.fontSize,
      fontWeight: cs.fontWeight, lineHeight: cs.lineHeight,
      letterSpacing: cs.letterSpacing, color: cs.color,
    },
    background: cs.backgroundColor,
    border: cs.border,
    borderRadius: cs.borderRadius,
    position: cs.position,
    zIndex: cs.zIndex,
  };
}

// Usage:
console.log(JSON.stringify(specFor('section.hero'), null, 2));
```

Copy the output into the component spec file under the relevant section.

## Phase 4 — Parallel Build

### Worktree setup

```bash
# From project root (must be a git repo):
git init && git add -A && git commit -m "chore: foundation"

# Create one worktree per component:
for name in Header Hero Features Pricing Footer; do
  git worktree add ../build-$name -b build/$name
done
```

### Builder dispatch

See `agents/builder.md` for the full agent prompt template.

Each builder agent run produces:
- The component file at `src/components/[Name].[ext]`
- A screenshot at `qa/builds/[name]-built.png`
- A self-check checklist at `qa/builds/[name]-checklist.md`

### Merging worktrees

```bash
# When all builders complete:
for name in Header Hero Features Pricing Footer; do
  git merge build/$name --no-ff -m "build: merge $name component"
done

# Clean up worktrees:
for name in Header Hero Features Pricing Footer; do
  git worktree remove ../build-$name
  git branch -d build/$name
done
```

## Phase 5 — QA

### visual-diff.js usage

```bash
node scripts/visual-diff.js \
  --original recon/screenshots/ \
  --clone http://localhost:3000 \
  --out qa/diff-report.html \
  --threshold 90
# Exits non-zero if any section scores below threshold
```

### Common fixes by symptom

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| Font renders as system fallback | Google Fonts blocked / typo in family name | Check network tab; verify exact family string from recon |
| Section background wrong color | CSS custom property not defined in globals | Add missing token to globals.css |
| Images stretched | Missing `object-fit: cover` or wrong aspect ratio | Add `object-fit` and explicit `width/height` |
| Hover animation missing | `transition` not on base state | Move `transition` property to default state, not `:hover` |
| Scroll animation fires immediately | IntersectionObserver threshold wrong | Adjust threshold; ensure initial state has `opacity: 0` |
| Mobile layout broken | Breakpoint px values differ from original | Re-check `recon/tokens.json` for media query values |
| Sticky header overlaps content | Missing `scroll-margin-top` on anchor targets | Add `scroll-margin-top: var(--header-height)` |
